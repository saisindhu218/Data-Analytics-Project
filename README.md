#  End-to-End Shopping Behaviour Analysis

An end-to-end Data Analytics project that analyzes customer shopping behavior using **Python, MySQL, and Power BI** to uncover purchasing patterns, customer segments, revenue trends, discount effectiveness, and subscription insights.

##  Project Overview
This project demonstrates the complete analytics workflow:
- Data Cleaning & Preprocessing using Python
- Exploratory Data Analysis (EDA)
- SQL-Based Business Analysis
- Interactive Power BI Dashboard Creation
- Business Insight Generation

##  Tech Stack
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- MySQL
- Power BI
- CSV Dataset

##  Project Structure
```text
├── customer_shopping_behavior.csv
├── customer_behavior_cleaned_aftershoppinganalysis.csv
├── shopping_analysis.ipynb
├── shopping_behaviour.sql
├── customer_shopping_behaviour_dashboard.pbix
├── README.md
```

##  Key Business Questions
- Revenue generated by Male vs Female customers
- Impact of discounts on customer spending
- Highest-rated products
- Subscriber vs Non-Subscriber spending analysis
- Customer segmentation (New, Returning, Loyal)
- Most purchased products by category
- Revenue contribution by age group

##  Dashboard Insights
- Customer Demographics Analysis
- Revenue & Sales Trends
- Product Performance Analysis
- Subscription Behavior
- Discount Effectiveness
- Customer Segmentation

##  Key Findings
- Male customers generated higher overall revenue.
- Express shipping customers showed slightly higher average spending.
- Discount campaigns significantly influenced purchase behavior.
- Loyal customers contributed a major share of total revenue.

##  How to Run
1. Open `shopping_analysis.ipynb` for data preprocessing and EDA.
2. Execute SQL queries from `shopping_behaviour.sql` in MySQL.
3. Open `customer_shopping_behaviour_dashboard.pbix` in Power BI Desktop.
4. Explore dashboard insights and business recommendations.
